## 💻 How to View & Run

1. **Local Browser**:
   Double-click `index.html` to open it directly in any web browser (Chrome, Edge, Firefox, Safari).

2. **VS Code Live Server**:
   Open this folder in VS Code, right-click `index.html`, and select **"Open with Live Server"**.

3. **Free Online Deployment**:
   - **GitHub Pages**: Push this repository to GitHub, go to **Settings > Pages**, and select `main` branch.
   - **Vercel / Netlify**: Drag and drop this folder directly to Netlify or import the Git repository into Vercel for instant deployment.
